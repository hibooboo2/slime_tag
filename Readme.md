# Slime Tag

A simple game made with Ebiten.

## Controls

w, s - forward and backward
a, d - left and right
space - attack
shift - run
escape - pause

## Controls for menu

up and down to navigate
enter to select

# Enemies

Enemies randomly spawn in the map and move randomly.
They also attack randomly. if they are touching you and attacking you will lose health.

# Game Over

When you die, you can press r to restart the game.
